# 万能嗅探

面向 Via Android 的轻量媒体识别与网页内试播用户脚本。它在页面已经暴露媒体地址时提供一个小入口，用户点一下即可尝试播放；它不承诺破解网站播放器、DRM 或访问控制。

## 安装

在 Via 中打开 [万能嗅探脚本](https://raw.githubusercontent.com/zwmopen/wan-neng-shi-tan/main/wan-neng-shi-tan.user.js)，按提示添加并启用。也可以从本仓库下载 `wan-neng-shi-tan.user.js` 后，在 Via 的“设置 → 脚本”中导入。

## 功能

- 观察网页 `<video>`、`<audio>`、`<source>` 元素和 Resource Timing 资源记录。
- 识别常见 MP4、WebM、MOV、OGV、HLS (`.m3u8`)、DASH (`.mpd`) 与音频直链，并优先展示较适合直接播放的候选。
- 发现媒体后显示轻量入口；可在当前网页上方试播、打开原链接，或回到网页原播放器。
- 隐藏界面中的 URL 查询参数；候选仅保存在当前页面内存，页面离开后清除。

## 能力边界

- 纯用户脚本没有浏览器扩展的 `webRequest`、`declarativeNetRequest` 或 `chrome.debugger` 权限。它只能读取网页元素和浏览器公开的资源记录，不能看到所有网络请求或请求响应头。
- 服务器要求特定 Referer/Origin、短时签名、HLS/DASH 分片或 Via 内核不支持的格式时，试播可能失败；可回到网页原播放器。
- `blob:` / MSE 播放只提供定位原播放器的入口，不提取、下载或拼接媒体片段。
- 不解密 DRM，不绕过登录、付费墙或访问控制。请只播放你有权访问的内容。

## 隐私与权限

- `@grant none`，没有额外用户脚本 API 权限和第三方依赖。
- 不改写 `fetch` / XHR，不读取 Cookie，不写本地存储，不向外部服务器发送数据。
- 点“直接播放”或“打开 / 试播”后，浏览器会按用户选择访问媒体链接。

## 验收状态

当前版本是可导入的本地候选，代码尚未在 Via 真机和真实视频站点完成验收。无法据此声称所有站点都能嗅探或播放。
